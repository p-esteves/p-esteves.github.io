# Pietro Esteves - Portfólio Pessoal

Repositório do meu portfólio acadêmico e profissional. 
Este site foi desenhado para consolidar minha trajetória como **Cientista de Dados e Estatístico**

🔗 **[Acesse aqui](https://p-esteves.github.io/)**

## 🗂️ Estrutura do Projeto

O site é uma aplicação web estática ("Static Site") desenvolvida com as tecnologias base da web, focada em leveza, performance e design responsivo moderno:

- **HTML5:** Semântica estruturada.
- **CSS3:** Variáveis nativas e estilização avançada sem frameworks, garantindo exclusividade de interface.
- **JavaScript (Vanilla):** Funcionalidades de barra lateral responsiva, filtragem de projetos e navegação.

---
*Este repositório é uma adaptação customizada do template [vCard Personal Portfolio](https://github.com/codewithsadee/vcard-personal-portfolio) por codewithsadee, totalmente reestruturada para fins de portfólio pessoal.*
